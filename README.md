# Raytracing Python

Une petite implémentation du ray tracing en Python.

## Installation

### Windows

```bash
python -m venv raytracing
raytracing\Scripts\activate.bat
pip install -r requirements.txt
```

### Unix / macOS

```bash
python -m venv raytracing
source raytracing/bin/activate
pip install -r requirements.txt
```
